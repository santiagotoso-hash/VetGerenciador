# Assets por empresa

Cada empresa tem sua pasta aqui, com o nome igual ao `slug` dela (ex.: `vilapet-by-mary`):

    assets/<slug>/logo.jpg      logomarca exibida no menu lateral

O caminho da logo fica no campo `logo` da empresa (ex.: `/assets/vilapet-by-mary/logo.jpg`).
Arquivos desta pasta são públicos (servidos pelo site), então não guarde nada sensível.
